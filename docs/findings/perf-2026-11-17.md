# Speed on the owner's transcripts, 2026-11-17 (round 10)

Sizes, counts and times only. No transcript text, file name, project name or session id is recorded here.

## Data and machine

- Projects folder (read only): 42 project folders, 163 transcripts, 861.9 MB, 7 transcripts over 20 MB, largest 72.9 MB.
- Machine: 16 logical processors, .NET 10 (10.0.x), Windows 11. Release build of the core library and of the bench.
- Tool: `tools/OpenTail.Bullshark.Bench` (added in round 10 item 1). Each step runs in its own process, so the peak working set
  belongs to that step. "Run 1" is the first read in that process; "run 2" is the second read in the same process. The OS file
  cache was not dropped, so neither is a true cold-disk read.

Command for one step: `dotnet tools/OpenTail.Bullshark.Bench/bin/Release/net10.0/OpenTail.Bullshark.Bench.dll --only index --repeat 2`
(steps: `index`, `search`, `storage`, `effort`, `pager`, `overlap`; `--projects <folder>` reads another folder).
