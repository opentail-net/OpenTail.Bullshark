# Ideas from other AI tools and "smart" apps, 2026-11-18

Source: three Haiku researchers (CLI agents, IDE/GUI agents, non-coding smart apps) on 2026-11-18, each told to cite primary docs and mark
what it could not confirm. **Researcher-reported, not re-checked by the orchestrator**: check the source URL before relying on a detail.
Skipped on purpose: anything already built (see README), anything that types into a session for the owner (principle 3), anything that
merges or accepts a coder's work on its own.

## Shortlist (ranked by fit to "walk away, come back, carry on")

| # | Idea | From | What it would be here | Needs |
|---|---|---|---|---|
| 1 | **"While you were away" digest** | Slack Recap; Devin Session Insights | A card per session since the window was last used: state changes, files written, last assistant answer, open question. Built from transcripts and digests we already read. | Nothing |
| 2 | **Needs-you escalation, snooze and ack** | PagerDuty escalation; Datadog downtimes; Sentry snooze; HA notification tags | An unanswered Needs-you item re-sounds after N minutes; ack silences sound only; snooze for a time (re-alert at the end if still waiting). One card per session, updated in place (already so). Never types into a session. | Nothing |
| 3 | **"Ready for review" lane apart from "Blocked"** | Claude Code agent view; Linear Triage; Warp status model | A finished coder with changes is "ready for review", not "needs you because blocked". Different sound, different list, keys to mark reviewed/snooze. | Check `AttentionList` contract |
| 4 | **Command palette (Ctrl+K)** | PowerToys Command Palette; Raycast | Jump to a session, page (Storage, Limits, Library), or action; select first, run with a second key so a stop is never one key. | Nothing (WPF only) |
| 5 | **Health list apart from Needs-you** | Home Assistant Repairs | Problems of the setup itself (CLI missing, folder untrusted, daemon not running, config unreadable) in one list with a one-click fix or the manual step. | Look at `Core/Health` first |
| 6 | **Copy review prompt from the Changes tab** | Claude Code desktop line comments; Zed per-hunk review | Pick files/lines in Changes, "Copy prompt for the coder" to the clipboard (same pattern as the conflict "Copy resolve prompt"). Nothing is sent. | Nothing |
| 7 | **Quick capture** | Raycast Notes | Global hotkey or box adds an idea to a backlog file for the planner; never sent to a session. | Owner: where the file lives |
| 8 | **Run templates (recipes)** | Goose recipes; Gemini CLI role agents | Setup choices saved as named templates with a parameter (task text); export to a repo file. Partly there: session library and patterns. | Look at `PatternStore` |
| 9 | **PR/CI card** | Claude Code desktop | CI state next to the merge check. | `gh` installed; owner |
| 10 | **Restore points** | Cline, Claude Code, Gemini CLI checkpoints | Snapshot before a coder run so work can be compared/restored. **Not a real undo** (Bash edits and other sessions' edits are not covered): git stays the rollback. | Owner: writes to the repo/shadow repo |
| 11 | **Worktree per session** | Claude Code `--worktree`; Cursor | Already gated (trust a throwaway folder). | Owner gate |
| 12 | **Rules with traces** ("why did X not fire") | Home Assistant automations | Only worth it after 2 and 3 exist as rules; large. | Later |

## Not a fit

- Auto-nudge ("quiet 10 min, send continue"), a natural-language box that sends messages, auto-accept or auto-merge: break principle 3.
- Cursor's eight parallel agents: adds merge work; planner/coder roles are fixed.
- Aider architect mode: planner/coder already do it. Amp's cloud threads: remote, not local. Windsurf auto-memories: unconfirmed.
- Gemini CLI checkpoints: docs say replaced by Antigravity CLI for some tiers (2026-06-18), unconfirmed.
