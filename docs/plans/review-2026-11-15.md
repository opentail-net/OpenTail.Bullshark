## 2. Where the two stores disagree

Only the session name joins them. There is no lock and no single writer. The pass saves its whole snapshot (Core/Supervisor/SupervisorRunner.cs:44, 79) while the UI thread writes too.

| State | How it arises | Result now |
|---|---|---|
| spec, no record | new run; record lost in a race | Start, a duplicate if the session already runs |
| record, no spec | close race; crash between the two writes | "Other sessions", never supervised |
| record, empty id | failed start or id not read back | no retry; the real session may run unrecorded |
| record, not listed | died, `rm`, daemon restart | Resume with a paid prompt, for every past run |
| listed name, no record | any of the above | invisible; a Start duplicates it |

## 6. Plan

### Phase 1: no lost writes, no surprise sessions

Goal: the files cannot lose an update, and no fault starts a second session.

- [ ] One `Update(change)` per store, under a named mutex, with a unique temp name. The pass applies its own records, not its snapshot. Replace every Load-then-Save pair (finding 2).
- [ ] Runner: any exception from Start or Resume becomes `Failed`. `Program.cs` catches all (1).
- [ ] Policy: adopt by name before Start (4).
- [ ] No `[` is a failure, not an empty list. Bad JSON in a store or in `~/.claude.json` skips the pass with a message (5, 6).
- [ ] Close: list first, stop unless unlisted, catch all, say what happened. A closed tab stays closed (7, 8).
- [ ] Resume: solo restart prompt; refuse a listed session; one write for run and record; drop "ask one short question"; cap the brief length (9, 10, 11).
- [ ] Arm the timeout before the stdin write; kill on cancel (14).
- [ ] Logs follow `--state`; `--state` with no value is an error (16).
- [ ] Disable Start until the run is written (19).

Check: `dotnet test` passes with these new tests: `APassSurvivesAStartThatThrowsWin32Exception`, `ARecordForgottenDuringAPassStaysForgotten`, `AListedNameIsAdoptedNotStartedTwice`, `ACorruptStateFileIsReportedNotThrown`, `AListingWithNoArrayIsAFailure`, `AFullResumeGetsTheSoloRestartPrompt`.
