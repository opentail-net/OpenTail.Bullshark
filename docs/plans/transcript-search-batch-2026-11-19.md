## Contracts (read in the code 2026-11-19)
- `SearchView.cs` ~136-137 prints `digest.ProjectFolder` (the raw encoded folder) in result lines; `LimitsView.cs` ~183 prints `day.TopProject` (the encoded key from `UsageReport`). `FolderDisplay.Of(projectFolderKey, IEnumerable<string?> cwds)` (Core/Folders) returns the display label (leaf of the group's own working folder, full path for a tooltip, else the key); the rail and Storage already use it with `digest.Cwd` (`SessionWindow.Rail.cs`, `SessionWindow.Storage.cs` ~112). The group key must stay the encoded name everywhere it groups.
- Search results open through `SearchView.OpenRequested(digest, line)` -> `SessionWindow.OpenTranscriptAtAsync(digest, line)` -> `TranscriptView.ShowAsync(digest, focusLine, title)`; only a line number is passed today (no query, no highlight). `TranscriptPager.Open(path)` scans the whole file for line starts on every open; `ReadPage(start, count)` returns `TranscriptLine`s (raw text kept, results shown cut to 120 characters).
- `TranscriptView` shows lines as blocks; `EffortJump(text, line, tooltip)` and the search blocks are TextBlocks with mouse handlers only (no focus, no keyboard, no AutomationProperties). Clipboard use elsewhere: `AwayView`, `ChangesView` (`Clipboard.SetText` in try/catch).
- `TurnFacts.Read` (Core/Activity) reads per-turn facts in one pass; `EffortReport.From(lines)` has failed calls, rereads, loops (`FailingLoops`), compactions? (check), and line numbers for jumps.
- Keys: `OnPanePreviewKeyDown` handles Ctrl+Shift+P/N, zoom keys and paste; `[`/`]` and `Ctrl+F` must act **only when the transcript view has keyboard focus** (never while a terminal or a text box has it).
- Privacy: no transcript text in logs; copying to the clipboard is the owner's action. Principle 3: nothing is sent to a session; Show full result reads the file only.

- [ ] T4. **Find in this session.** `Ctrl+F` in the transcript view opens a small bar (a themed text box, "n of m", Enter next, Shift+Enter previous, Esc closes). A search result that opened the transcript passes its query so the highlight and "n of m" are ready. Core `TranscriptFind` (pure: lines in, hit line numbers out) + tests (case, overlap, a hit in a cut result's hidden part counts, cap, cancellation).
- [ ] T5. **Jump bar.** With the transcript focused: `[` and `]` go to the previous/next prompt; `{` and `}` (Shift) to the previous/next failure; `Alt+[`/`Alt+]` file write; compaction.
